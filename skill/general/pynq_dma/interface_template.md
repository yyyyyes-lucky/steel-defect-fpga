# DMA 接口与故障记录模板

本文件是【通用方法】模板；设备名、地址、位宽和缓存属性必须从当前 bit/hwh、驱动和日志确认，不能照抄其他项目。

- 板卡/器件/系统镜像/PYNQ 版本：
- bit 与 hwh 是否同一构建、接口实例名：
- 核寄存器、控制方式、done/error 语义：
- DMA 模式、输入/输出位宽、长度上限：
- 每次发送/接收的 shape、dtype、布局、字节数、TLAST：
- 缓冲区分配者、coherent/cacheable 属性：
- CPU 写入 → 设备读取的同步责任：
- 设备写入 → CPU 读取的同步责任：
- 接收、核启动、发送的实际顺序：
- 等待哪些通道，超时后如何确认状态：
- 输出复制/所有权、下一帧能否复用底层内存：
- 正常关闭流程与异常恢复流程：
- 症状、最小输入、首个错误、寄存器状态与日志：
- 修复假设、最小验证、仍未验证的情况：

示意生命周期：分配/复用 → 填充 → CPU到设备同步 → 接收与启动 → 等待全部完成 → 设备到CPU同步 → 复制/消费 → 正常释放。

本模板不预设固定地址或 PYNQ 自动缓存行为；不得把示意顺序当作特定 IP 的完整驱动。
