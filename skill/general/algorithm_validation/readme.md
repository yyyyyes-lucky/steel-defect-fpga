# 通用方法：验证图像算法输出

适用于检测框后的二值掩膜、候选区域、粗分割或图像统计流程。程序无报错不等于图像结果可信；本流程强调保存中间结果、按类别检查和保留人工判断。它不能替代带像素级真值的数据集评价。

## 准备材料

- 固定原图与检测框或 ROI；
- 算法版本、阈值、形态学参数和面积筛选参数；
- 原始掩膜、处理后的输出和候选区域统计；
- 覆盖典型情况的人工复核样本，包括空结果、细小目标和纹理复杂样本。

使用[图像复核模板](review_template.md)记录每次检查。

## 检查步骤

1. 明确输出含义：检测框、精确掩膜、候选区域或统计值。界面和报告不能把候选区域称为精确轮廓。
2. 保存并检查原始输出，再检查后处理输出；不要先用形态学或面积过滤掩盖原始问题。
3. 按类别或场景检查细目标丢失、大区域粘连、噪声、偏移及空样本误报。不同类别可能需要不同策略。
4. 每轮只改变一个参数，结果文件名包含参数和版本，不覆盖前一次输出。
5. 同时查看正例与空例。候选区域减少本身不代表质量提高；应检查目标保留、噪声、边界偏差及人工复核结论。
6. 如果某一类别的旧分支更稳，可以保留旧分支；不要因为其他类别改进而整体替换。
7. 确认功能和视觉效果后再比较速度；如需调整算法来换速度，应另外验证质量影响。

## 结果记录

记录输入样本、算法版本、参数、候选像素数、连通域数、复核状态和采用决定。连通域数不是实际目标数，像素数也不是精度指标。需要 IoU、召回率或其他质量指标时，必须有相应标注真值和独立评价流程。

## 限制

只保存最好看的样本、反复在同一验证集调参后把它当独立测试，或没有固定输入和参数时，不能据此得出质量结论。视觉复核可发现问题，但不能替代有真值的定量评估。
