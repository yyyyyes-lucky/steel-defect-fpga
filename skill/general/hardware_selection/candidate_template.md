# 候选筛选记录模板

本文件是【通用方法】的待填写模板，不是本项目新的实验结果。填写时请把“实测、估计、未验证”分开。

- 候选名称与日期：
- 基线/候选版本：
- 输入尺寸、类型、容量及异常输入行为：
- 输出契约、允许误差及黄金参考：
- 同输入的计时边界、是否含 DMA/缓存/打包/解包：
- 目标阶段平均/尾延迟、调用次数、占总体比例：
- 理论最大可节省时间、实际替换预算：
- 核时间 / 传输与等待 / 剩余软件分别有哪些证据：
- 新增 LUT/FF/BRAM/DSP、时钟和时序余量：
- 软件回退与未覆盖场景：
- 已有相似候选及本次新增假设：
- 原语、系统、小样本、全量分别完成到哪一步：
- 原始报告位置：
- 结论（采用 / 停止本实现 / 需要新证据）：

停止条件必须在比较前写明，例如整体收益下限、资源上限、尾延迟容忍度；这些值由项目目标决定，不照搬本项目阈值。
