# 复现问题记录模板

本文件是【通用方法】模板。项目案例应另填版本、路径和证据，不要把本项目的命令当成固定答案。

- 编号、发现日期、软件/硬件版本：
- 操作位置（Windows / 板端 Terminal / Notebook）：
- 实际工作目录、工具/解释器路径：
- 原文步骤、实际执行命令、预期结果：
- 第一处真实错误、完整日志位置：
- 已确认原因与尚未确认假设：
- 最小修复及为何有效：
- 本地检查 / 模拟 / 实物板测分别完成什么：
- 哪些现有结果可以复用、不必重测：
- 文档需要同步更新的章节：
- 复测结果、证据文件及仍有限制：

不要将“未运行”“失败”“已修复但未验证”“已完成验证”混为同一个状态。
