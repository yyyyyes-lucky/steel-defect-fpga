# 本项目案例：类别化图像算法复核

通用检查方法见 [general/algorithm_validation](../../general/algorithm_validation/readme.md)。这里记录本项目的输出边界和人工取舍。

## 输出边界与最终选择

- Windows 端 YOLO 负责检测框和置信度；开发板执行检测框后的特征/后处理链。
- 裂纹只展示 YOLO 检测框和置信度，不生成 FPGA 裂纹掩膜。
- 麻面不虚构精确轮廓；统计结果不能解释为真实缺陷像素精度。
- 划痕保留旧算法分支；夹杂、斑块、氧化皮压入采用人工复核后选定的候选区域分支。

## 复核发现

低阈值下，纹理可能连成接近整图的大区域；提高阈值后又可能出现碎片。人工检查促使项目按类别保留分支，并同时查看原始输出、叠加图和统计值。最小面积和形态学操作用于候选区域处理，不据此宣称像素级分割精度或真实缺陷个数。

相关图片和网页位于 [复刻演示材料](../../../data/reproduction_20261031/)。数据集、检测框和阈值改变后需重新复核。
