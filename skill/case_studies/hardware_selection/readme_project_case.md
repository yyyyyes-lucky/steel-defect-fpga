# 本项目案例：硬件候选筛选

本文件只记录本项目的实测和取舍；通用流程见 [general/hardware_selection](../../general/hardware_selection/readme.md)。版本号、数字和证据路径不能直接移植到其他工程。

## 采用的基线

最终工程采用 v10 + v9.1 combined + Q8 staged/minmax + explicit cache 及经人工复核的掩膜算法。未把每个功能通过的候选都并入最终路径。

## 候选结果

| 候选 | 证据 | 决定 |
| --- | --- | --- |
| v11 CCL | 全量系统用例与代表配对计时；class2 约 1.02495×，未有旧全量报告证明稳定收益 | 未纳入 |
| v12 阶段筛选 | class2 selection chain 约占当次 16.92%，属于优化预算，不是新硬件收益 | 作为分析依据 |
| v13 class2 融合 | 184 帧/403 ROI 同 Overlay 对照约 1.00566×；BRAM 136.5/140（97.50%） | 未纳入 |
| v14 描述子归约 | 原语和输出检查通过，局部 DMA 计时不足以证明系统加速 | 未纳入 |
| v15 描述子集成 | 全量总耗时增加约 5.998% | 停止 |
| v16 夹杂 Gaussian 复用 | 受影响帧总耗时增加约 0.745%，保留 PS 路径 | 停止硬化 |
| F1 边缘计数融合 | 平均节省约 0.619%，8 个会话对区间跨零 | 未晋级 |
| P2/F3 | 初筛整体慢约 1.216%，目标 class2 慢约 6.899% | 停止，不与 F1 组合 |

详细原始材料见 [优化取舍](../../../report/optimization_history.md) 和 [优化证据](../../../data/optimization_evidence/readme.md)。这些结论只适用于对应输入、计时边界和实现。
