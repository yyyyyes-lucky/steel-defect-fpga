# 六类钢材表面缺陷数据集

本目录保留项目使用的数据集划分、图像和 YOLO 检测框标签。类别顺序为：裂纹、夹杂、斑块、麻面、氧化皮压入、划痕；标签不包含像素级分割真值。

| 目录 | 图像数 | 标签数 | 用途 |
| --- | ---: | ---: | --- |
| train | 5756 | 5756 | 完整训练分区 |
| valid | 179 | 179 | 验证分区 |
| test | 181 | 181 | 测试分区 |
| demonstration | 120 | — | 从 valid 选取的静态演示原图，每类 20 张 |

train、valid、test 共 6116 张图像。demonstration 是 valid 中图像的副本，不是额外的独立测试集。

## 训练配置与最终权重

- `data.yaml` 指向完整 train/valid/test 分区。
- `train_originals.txt` 列出最终微调实际使用的 1439 张训练图像，路径相对于本目录。
- `retrain_data.yaml` 使用上述清单作为训练输入，使用 179 张 valid 图像进行验证。因此，最终权重不能描述为使用全部 5756 张训练图像得到。
- 训练从旧版权重初始化，最佳权重对应第 12 轮；连续 15 轮未改善后，在第 27 轮自动停止。详情见[训练记录](../models/training/readme.md)。

配置及训练清单采用相对路径。数据读取时生成的 labels.cache 不属于原始标注，未收录。

## 静态演示输入

本目录保存原始 JPG；[冻结静态输入](../static_inputs/inputs.json)保存原图对应关系、灰度处理输入与检测框记录。演示原图来源为 valid，ARM/FPGA 对照用于验证后处理输出和耗时，不能据此宣称独立测试集上的分割精度。
